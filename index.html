데이터는 이 브라우저에만 저장됩니다 (localStorage)

학생 번호별 성별

원서 용지에는 성별 표시가 없어서 별도로 입력합니다. 학생 번호(예: 3-2-15)를 입력하고 성별을 선택하세요. 남고(성남고·성일고)·여고(성남여고·분당영덕여고) 기재 여부를 검증할 때 사용됩니다.
학생 번호성별
형식: A열 = 반, B열 = 번호, C열 = 성별(남/여). 학년은 모두 3학년으로 자동 처리되어 "3-반-번호" 형태의 학생 번호로 저장됩니다. 제목 줄이 있어도 자동으로 건너뜁니다. 이미 있는 학생 번호는 새 값으로 덮어씁니다.

학교별 예상 마감 지망순위

선생님이 직접 확보한 자료(예상치)를 입력하세요. 모르는 학교는 빈칸으로 두면 "정보 없음"으로 처리되어 전략 검증(6번 항목)에서 자동으로 제외됩니다 — 억지로 채울 필요 없습니다.
정원이 성별에 따라 다르므로 남 / 여를 구분해서 입력합니다. 남고·여고처럼 한쪽 성별만 지원 가능한 학교는 반대쪽 칸이 자동으로 비활성화됩니다.
구역학교남 예상 마감 지망여 예상 마감 지망
형식: A열 = 학교명(목록 표기와 정확히 일치, 예: 낙생고), B열 = 남 예상 마감 지망, C열 = 여 예상 마감 지망. 모르거나 해당 없는 칸은 비워두거나 "x"로 두면 "정보 없음"으로 처리됩니다. 목록에 없는 학교명은 무시됩니다.

Google Gemini API 키

원서 이미지를 인식하려면 Google Gemini API 키가 필요합니다. aistudio.google.com/apikey에서 결제(유료) 등급으로 발급받은 키를 사용합니다. 유료 등급은 무료 등급과 달리 분당/일일 요청 수 제한이 사실상 여유로워 인식 요청이 대기 없이 바로바로 처리됩니다.
키는 이 브라우저에만 저장되며, 인식 요청을 보낼 때만 이미지와 함께 Google 서버로 전송됩니다.

원서 이미지/PDF 업로드

이미지(jpg, png 등)와 PDF 모두 올릴 수 있습니다. 여러 학생의 원서가 한 PDF에 여러 페이지로 들어있으면 됩니다.
이름을 미리 가리지 않고 올려도 됩니다. 올린 뒤 아래 미리보기에서 마우스로 드래그해서 이름 부분을 검게 가려주세요. 검게 칠한 부분은 서버로 전송되는 이미지 자체에서 지워진 뒤에만 인식 요청이 전송되므로, 이름 원본 픽셀은 Google 서버로 나가지 않습니다. 학생 번호(학년-반-번)는 가리지 마세요.
이미지 또는 PDF를 여기로 끌어놓거나 클릭해서 선택하세요
드래그해서 이름 위치를 가리세요. 위치는 자동 저장되어 다음 이미지/페이지에도 그대로 적용됩니다.
가리기 위치만 맞춰두고 "일괄 검증"을 누르면, 지금 올린 파일의 모든 페이지(PDF면 전체 페이지, 이미지면 이 1장)를 자동으로 인식해서 바로 저장합니다. 저장된 내용은 검증 결과 탭에서 바로 확인·수정할 수 있습니다.

인식 결과 확인 · 수정

손글씨 인식은 틀릴 수 있습니다. 저장 전에 꼭 원본 이미지와 대조해서 확인하세요.

학군내 (1~5지망)

구역내 (1~19지망, 안 쓴 칸은 비워두기)

특이사항 (오른쪽 체크박스 칸)

체크된 항목이 있으면 한 줄에 하나씩 적으세요 (예: "교직원(행정직 포함) 자녀 타교 배정 지원 (분당고등학교)"). 체크된 게 없거나 "해당 없음"만 체크된 경우 비워두세요.

저장된 학생 검증 결과

성별표나 마감 지망순위, 학생 정보를 나중에 고친 뒤 이 탭에 그대로 있는 상태라면 "재검증"을 눌러 최신 값으로 다시 확인하세요. 탭을 벗어났다가 돌아오면 자동으로 다시 확인됩니다. 학생 번호가 "3학년 7반 16번"처럼 다르게 표시되거나 성별을 찾지 못하는 경우 "학생 번호 정리"를 눌러 "3-7-16" 형태로 통일하세요.
